# Security Policy

## Supported Versions

I only actively maintain the latest version of WebSumize.

| Version | Supported |
|--------|----------|
| latest | Yes |
| older  | No |

---

## Reporting

If you find a security issue, you can report it either publicly or privately.

---

## What to Include

When reporting, please include:

- What the issue is
- How to reproduce it
- Where it happens in the app
- Any relevant screenshots or logs

---

## Response Time

- I usually respond within a few days, or at most within a month  if I don’t forget.
- I will let you know once the security issue is fixed.

---

## Scope

This policy applies to:
- WebSumize source code
- Official releases

It does not apply to:
- Third-party services
- Forks or modified versions
